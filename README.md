# 🚀 Full Stack Web Development Roadmap

مرحباً بك في المستودع الخاص بمسار تعلم تطوير الويب الكامل (Full Stack Web Development). يهدف هذا المستودع إلى توثيق التطبيقات والأكواد والمشاريع التي تم بناءها خلال رحلة التعلم والتطبيق العملي.

---

## 🛠️ Tech Stack & Tools

### **Backend Development**
* **Language:** C#
* **Framework:** ASP.NET Core MVC
* **ORM:** Entity Framework Core
* **Database:** SQL Server

### **Frontend Development**
* HTML5 / CSS3
* JavaScript (ES6+)
* Bootstrap

### **Tools & Environment**
* Visual Studio / VS Code
* Git & GitHub
* SQL Server Management Studio (SSMS)
